# Лабораторна робота №3

## Тема, мета та опис проєкту

- **Тема:** Побудова макета вебсторінки засобами CSS Flexbox і Grid. Створення, оформлення та базова перевірка HTML-форми.
- **Мета:** Навчитися свідомо обирати Flexbox або Grid для компонування елементів, керувати напрямком, вирівнюванням і проміжками, а також створити семантичну й доступну форму з вбудованою перевіркою без використання JavaScript.
- **Опис:** Вебсайт локальної міської кав'ярні «Доброго дня!».

## Компонування сторінки

- **Flexbox:** Застосовано для одновимірного вирівнювання шапки сайту та блоку навігації (`.header-container`, `.main-nav`). Елементи розташовані на одній лінії по центру вздовж осі без небажаного перенесення рядків, із фіксованими проміжками через `gap`.
- **Grid:** Застосовано для двовимірного блоку карток меню (`.cards-grid`) із шаблоном `repeat(2, minmax(0, 1fr))` та відступами `gap`, а також для вертикальної організації блоків форми бронювання (`.booking-form`, `.form-field`).

## Форма та перевірка даних

- **Призначення:** Форма онлайн-бронювання столика (`.booking-form`).
- **Поля та доступність:**
  - Усі поля мають унікальні `id` та атрибути `name`.
  - Підписи `<label>` явно прив'язані до відповідних полів через атрибут `for`.
  - Використано елементи: `<input type="text">`, `<input type="tel">`, `<input type="date">`, `<select>`, `<textarea>` та кнопку `<button type="submit">`.
- **Вбудована перевірка (HTML Validation):**
  - `required` — обов'язковість заповнення ключових полів форми;
  - `minlength="2"` — мінімальна допустима довжина імені клієнта;
  - `min="2026-10-15"` — обмеження вибору дати з календаря.
- **Стани:** Оформлено стан `:focus-visible` з чітким контуром для навігації з клавіатури та стан `:invalid` із червоною рамкою для виділення некоректних даних.
