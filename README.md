## Лабораторна робота № 8 — Обробка форм і збереження користувацьких даних

**Тема:** Обробка форм, базове керування даними (Create–Read–Delete) та збереження стану в `localStorage`.  
**Мета:** Реалізувати читання та валідацію даних форми, створення й видалення власних записів без перезавантаження сторінки та їх відновлення після оновлення.

### Запуск проєкту

1. Відкрити папку проєкту у VS Code.
2. Запустити через розширення **Live Server** (`Go Live`) за фіксованою адресою та портом.

### Нові модулі

- **`js/storage.js`** — читання та запис масиву записів у `localStorage` за ключем `dobrogo-dnya-lab8:user-wishes:v1`, а також перевірка структури об'єктів при відновленні.
- **`js/userItems.js`** — обробка події `submit` форми `#user-item-form`, валідація полів (`trim()`), генерація `id` через `crypto.randomUUID()`, безпечне виведення через `textContent` та видалення записів за `data-delete-id`.
- **`js/main.js`** — виклик `initUserItems()` незалежно від завантаження каталогу з ЛР № 7.

### Основні реалізовані функції

- Валідація назви (3–80 символів), категорії та опису (10–500 символів).
- Додавання нового запису до списку та збереження у `localStorage`.
- Видалення запису за унікальним `id` та відображення порожнього стану (`#user-empty`).
- Відновлення збережених записів під час завантаження сторінки з обробкою помилок читання/запису.
