# Лабораторна робота №3

## Тема, мета та опис проєкту

- **Тема:** Побудова макета вебсторінки засобами CSS Flexbox і Grid. Створення, оформлення та базова перевірка HTML-форми.
- **Мета:** Навчитися свідомо обирати Flexbox або Grid для компонування елементів, керувати напрямком, вирівнюванням і проміжками, а також створити семантичну й доступну форму з вбудованою перевіркою без використання JavaScript.
- **Опис:** Вебсайт локальної міської кав'ярні «Доброго дня!».

## Компонування сторінки

- **Flexbox:** Застосовано для шапки сайту (`.header-container`) у вигляді колонки (`flex-direction: column`) із вертикальним і горизонтальним центруванням вмісту, а також для горизонтального навігаційного меню (`.main-nav`) в один неподільний рядок без небажаних переносів завдяки `gap` та `flex-wrap: nowrap`.
- **Grid:** Застосовано для двовимірної сітки карток меню (`.cards-grid`) із шаблоном `repeat(2, minmax(0, 1fr))` та відступами `gap`, а також для вертикальної організації блоків форми бронювання (`.booking-form`, `.form-field`).

## Форма та перевірка даних

- **Призначення:** Форма онлайн-бронювання столика (`.booking-form`).
- **Поля та доступність:**
  - Усі елементи форми мають чіткі атрибути `name` та унікальні `id`.
  - Підписи `<label>` явно пов'язані з відповідними елементами керування за допомогою атрибута `for`.
  - Використано елементи: `<input type="text">`, `<input type="tel">`, `<input type="date">`, `<select>`, `<textarea>` та кнопку відправки `<button type="submit">`.
- **Вбудована перевірка (HTML Validation):**
  - `required` — обов'язковість заповнення обов'язкових полів форми (ім'я, телефон, дата, кількість гостей);
  - `minlength="2"` — мінімальна допустима довжина текстового введення для імені клієнта;
  - `min="2026-10-15"` — обмеження вибору дати візиту не раніше поточної дати.
- **Стани елементів:** Оформлено стан `:focus-visible` із контрастним контуром для доступної навігації з клавіатури та `:invalid` для підсвічування некоректно заповнених полів червоним кольором.
