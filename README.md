## Лабораторна робота № 9 — Перехід від JavaScript до Vue 3 та компонентної структури

**Тема:** Створення Vue 3 проєкту за допомогою Vite, перенесення інтерфейсу попередньої роботи та поділ його на базові компоненти.  
**Мета:** Навчитися працювати з однофайловими компонентами (`.vue`), реактивними даними (`ref`, `computed`), директивами (`v-model`, `v-for`, `v-if`), подіями, `props` та `emits`.

### Що було змінено та реалізовано

У межах роботи сайт кав'ярні «Доброго дня!» перенесено зі звичайного JavaScript на компонентну архітектуру Vue 3. Замість ручного пошуку елементів у DOM і створення HTML-карток через JS-скрипти інтерфейс розділено на окремі незалежні компоненти, а оновлення списків відбувається автоматично через реактивні змінні.

Основні зміни:

- Дані основного меню винесено у локальний JS-модуль, а фільтрацію за пошуковим запитом і категорією реалізовано через обчислювану властивість `computed` замість ручної перемальовки списку.
- Стан пошукового рядка, обраної категорії та полів форми зв'язано зі змінними за допомогою директиви `v-model`.
- Виведення карток меню та власних записів переведено на декларативний цикл `v-for` зі стабільним `:key` за унікальним `id`, а порожні стани списків керуються через `v-if` / `v-else`.
- Керування списком власних побажань зосереджено у батьківському компоненті: дочірня форма перевіряє дані й передає новий запис нагору через подію `add`, а картка запису повідомляє про видалення через подію `delete`.

### Компоненти, `props` та `emits`

- **`App.vue`** — головний компонент, зберігає реактивний стан пошуку (`query`), категорії (`category`), список власних записів (`userItems`) та обчислює відфільтроване меню через `computed`.
- **`MenuList.vue`** — отримує масив `items` і прапорець `removable` через `props`, виводить картки циклом `v-for` зі стабільним `:key="item.id"` і передає подію `delete` нагору.
- **`MenuCard.vue`** — відображає окрему позицію меню або власний запис через `props.item`; за наявності `removable` генерує подію `emit('delete', item.id)`.
- **`UserWishForm.vue`** — керує полями форми через `v-model`, перевіряє коректність введених даних і надсилає новий запис батьківському компоненту через `emit('add', record)`.
