## Лабораторна робота № 11: Завантаження даних із зовнішнього API у Vue 3 та Pinia

У межах одинадцятої лабораторної роботи застосунок кав'ярні «Доброго дня!» інтегровано із зовнішнім відкритим REST API TheMealDB (документація: https://www.themealdb.com/api.php) за допомогою GET-запиту до endpoint `https://www.themealdb.com/api/json/v1/1/filter.php?c=Dessert` для динамічного завантаження розділу десертів та випічки, тоді як базові позиції кави й чаю зберігаються локально у `src/data/menuItems.js` та об'єднуються в єдиний каталог. Для отримання зовнішніх даних створено сервісний модуль `src/services/menuApi.js`, який виконує асинхронний `fetch()`, перевіряє статус відповіді через `response.ok`, валідує наявність масиву `meals` у JSON-відповіді та проводить нормалізацію зовнішніх полів (`idMeal`, `strMeal`, `strMealThumb`) у внутрішню схему застосунку (`id`, `title`, `category`, `description`, `image`, `time`, `details`). У сховищі Pinia (`src/stores/menu.js`) реалізовано асинхронний екшен `loadItems(force)` із конструкцією `try/catch/finally` та захистом `hasLoaded` від зайвих повторних запитів, а також екшен `retry()` для повторного завантаження при збоях мережі. У компонентах `HomeView.vue` та `DetailView.vue` реалізовано взаємовиключне відображення чотирьох станів запиту (`loading`, `error`, `empty`, `success`) та підтримку прямого відкриття детальної сторінки за URL, при цьому публічний API працює без секретних ключів і без обмежень лімітів для навчальних запитів.
